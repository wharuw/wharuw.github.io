# 뮤아르 스튜디오 홈페이지 — 배포 & 사용 가이드

여자친구분이 코드를 몰라도 **색상 테마, 폰트/글자 크기, 소개 문구, 서비스 목록,
포트폴리오(이미지 업로드 포함)** 를 직접 수정할 수 있도록 만든 사이트입니다.

- 공개 페이지: `index.html` (방문자가 보는 화면)
- 관리자 페이지: `/admin` (로그인한 사람만 수정 가능)
- 실제 콘텐츠: `content/site.json` (관리자 페이지에서 저장하면 이 파일이 자동으로 바뀝니다)

한 번만 아래 순서대로 설정해두면, 이후에는 여자친구분이 `/admin` 주소에서
로그인해서 수정 → 저장 버튼만 누르면 몇 분 안에 실제 사이트에 반영됩니다.
(다시 코드를 열거나 git을 몰라도 됩니다.)

---

## 1. GitHub 저장소 만들기

1. [github.com](https://github.com) 계정이 없다면 하나 만듭니다.
2. 새 저장소(Repository)를 만듭니다. (Public/Private 상관없음)
3. 이 폴더(`muare-site`) 안의 파일 전체를 그 저장소에 업로드(push)합니다.
   - GitHub 웹사이트의 "Add file → Upload files" 로 드래그해서 올려도 되고,
   - `git init` → `git remote add origin ...` → `git push` 로 올려도 됩니다.

## 2. Netlify에 배포하기

1. [app.netlify.com](https://app.netlify.com) 에서 계정을 만들고 로그인합니다.
2. **Add new site → Import an existing project** 선택
3. GitHub 계정을 연결하고, 방금 만든 저장소를 선택합니다.
4. 빌드 설정은 그대로 두면 됩니다.
   - Build command: 비워두기
   - Publish directory: `.` (마침표 하나, 기본값)
5. **Deploy site** 클릭 → 몇 초 후 `https://아무이름.netlify.app` 형태의 주소가 생깁니다.
   - 원하면 Site configuration → Domain management 에서 원하는 이름이나
     보유한 커스텀 도메인으로 바꿀 수 있습니다.

## 3. 로그인 기능(Identity) 켜기

이 단계가 있어야 `/admin` 페이지에서 아무나가 아니라 **초대받은 사람만** 수정할 수 있습니다.

1. Netlify 대시보드에서 방금 만든 사이트로 들어갑니다.
2. **Site configuration → Identity → Enable Identity** 클릭
3. 같은 화면에서 **Registration preferences** 를 **Invite only** 로 설정합니다.
   (아무나 가입해서 사이트를 수정하지 못하도록 막는 설정입니다.)
4. 아래로 스크롤해서 **Git Gateway → Enable Git Gateway** 클릭
   (이 기능이 "저장" 버튼을 눌렀을 때 실제로 GitHub 저장소를 수정해 줍니다.
   별도의 비밀번호나 토큰을 직접 관리할 필요가 없습니다.)

## 4. 여자친구 계정 초대하기

1. **Site configuration → Identity → Invite users** 클릭
2. 여자친구분의 이메일 주소를 입력해서 초대 메일을 보냅니다.
3. 여자친구분이 메일의 링크를 클릭하면 비밀번호를 설정하는 화면이 뜨고,
   설정이 끝나면 자동으로 관리자 페이지(`/admin`)로 이동합니다.

---

## 5. 사용 방법 (여자친구분 안내용)

1. 브라우저에서 `https://사이트주소/admin` 으로 접속
2. 이메일/비밀번호로 로그인
3. 왼쪽 메뉴의 **"사이트 설정"** 클릭 → **"전체 설정"** 클릭
4. 아래 항목들을 원하는 대로 수정
   - **색상 테마**: 배경색, 글자색, 포인트색 등을 색상 선택기로 변경
   - **폰트 & 글자 크기**: 제목/본문 폰트, 전체 글자 크기(작게/기본/크게) 선택
   - **메인 화면(히어로)**: 첫 화면 문구, 배경 이미지 교체
   - **소개(About)**: 소개 문구, 프로필 사진 교체
   - **서비스 목록**: 서비스 이름/설명 수정, 목록에 항목 추가·삭제·순서 변경
   - **포트폴리오**: 작업명/카테고리 수정, **이미지 직접 업로드**,
     오른쪽 위 버튼으로 새 작업 추가, 드래그로 순서 변경, 휴지통 아이콘으로 삭제
   - **연락처**: 문의 이메일 주소
5. 다 수정했으면 오른쪽 위 **"Publish"**(저장/게시) 버튼 클릭
6. 1~3분 정도 후 실제 사이트에 반영됩니다. (Netlify가 자동으로 새로 배포합니다)

> 이미지는 업로드하면 자동으로 저장소의 `images/uploads` 폴더에 저장되고,
> 사이트에도 자동으로 연결됩니다. 파일 용량이 너무 크면(수십 MB 이상)
> 업로드가 느릴 수 있으니, 가능하면 2~3MB 이하로 준비해 주세요.

## 참고 사항

- **레이아웃/애니메이션처럼 구조 자체를 바꾸는 큰 수정**은 관리자 페이지에서는
  할 수 없고, `index.html`의 코드를 직접 수정해야 합니다. (이 부분은 필요할 때
  다시 요청해 주시면 도와드릴 수 있습니다.)
- 관리자 페이지에서 저장한 내용은 GitHub 저장소의 커밋 기록으로 남기 때문에,
  실수로 잘못 저장해도 이전 버전으로 되돌릴 수 있습니다.
- 로컬에서 `index.html`을 그냥 더블클릭해서 열면 `content/site.json`을 불러오지
  못해 초기 기본 디자인으로만 보입니다 (정상입니다). 실제 배포된 사이트에서는
  정상적으로 저장된 내용이 반영됩니다.
